Xera Browser — Ad Blocking: Old vs New

How we went from a single EasyList toggle to a uBlock-compatible, TV-friendly shields system — without rewriting the wheel.

Package: dev.xera.browser Engine: com.github.truefedex:ad-block (AdBlockClient) Version: 2.1.6-xera-ublock1 Policy: master toggle stays single source of truth

TL;DR

Old: 1 list, 1 URL field, 30-day cache, instant toggle, no insight → New: 5+ uBlock defaults, per-list switches, 7-day cache, overlay with metrics + SHIELDS ON pill

Old was EasyList only → new is EasyList + EasyPrivacy + Peter Lowe + Badware + uBO filters concatenated and fed to the same AdBlockClient. No new native engine, just a smarter data + UI layer on the TV Bro codebase.

OLD Single-list strategy

Data

  • One URL in Config.adBlockListURL → DEFAULT_ADBLOCK_LIST_URL = https://easylist.to/easylist/easylist.txt
  • No per-list control; user could paste one custom URL only
  • AdblockModel.kt:36 fetches one file, client.parse(easyList)
  • Cache: filesDir/adblock_ser.dat via client.serialize() valid 30 days (AUTO_UPDATE_INTERVAL_MINUTES = 43200)

Blocking

  • WebViewEx.kt:363 shouldInterceptRequest → if isAdBlockingEnabled() → isAd(request, baseUri) → client.matches(url, filterOption, baseHost)
  • mapRequestToFilterOption() maps image/css/script/object via MIME + extension, else UNKNOWN

UI

  • Bottom bar ibAdBlock → instant toggleAdBlockForTab() flip, no confirmation
  • Settings → Main → single Switch scAdblock + one EditText etAdBlockerListUrl + Refresh
  • No total stats, no per-page context, no visible brand beyond “TV Bro”
WebView → WebViewClient.shouldInterceptRequest → MainActivity.isAd() → AdblockModel.isAd() → AdBlockClient.matches() → single easylist.txt Toggle: ibAdBlock → toggleAdBlockForTab() → immediate Settings: scAdblock + etAdBlockerListUrl (1)

NEW uBlock-style multi-list

Data

  • 5 defaults in Config.kt:51 DEFAULT_UBLOCK_LIST_NAMES/URLS:
    EasyList, EasyPrivacy, Peter Lowe, Badware (.../uAssets/.../badware.txt), uBO filters (.../filters.txt)
  • + 2 extras opt-in: Privacy, Annoyances
  • Enabled set Config.adBlockEnabledLists: Set<String> (ADBLOCK_ENABLED_LISTS_KEY) — defaults all 5, persisted as StringSet
  • AdblockModel.kt:36 concatenates all enabled URLs → one combinedText → client.parse(combinedText); tolerates single-list failure, falls back to cache
  • Cache same adblock_ser.dat but 7-day refresh, plus lastError/blockedCount observables; adBlockStatsBlocked persisted

Blocking

  • Same WebViewEx:363 hook + client.matches() — now matcher sees ~5× rules, including hosts-format Peter Lowe
  • Stats increment on block → total persisted

UI

  • Bottom bar ibAdBlock → showAdBlockOverlay() instead of instant toggle
  • Overlay AdBlockOverlayDialog.kt:17 + dialog_adblock_overlay.xml:1 (uses R.style.SettingsDialog — TV Bro default style, will be redesigned): SHIELDS ON — Xera, blocked on page / total, lists enabled count, last update, host, Switch, Manage → Settings
  • Subtle brand pill tvShieldsOn (shields_on_bg.xml) above bottom panel, GONE when off — visible but not shouting
  • Settings → dedicated card (MainSettingsView.kt:244 initAdBlockConfigUI → buildUblockListsUI()) with CheckBoxes per list + custom URL field + stats/error
WebView → shouldInterceptRequest → isAd() → AdblockModel.isAd() (+incrementAdBlockStats) → client.matches(url, filterOption, baseHost) → concatenated: easylist + easyprivacy + yoyo + badware + filters [+ extras] [+ custom] Toggle: ibAdBlock → AdBlockOverlayDialog (metrics + Switch) → onToggle → tab.adblock / config.adBlockEnabled Indicator: tvShieldsOn pill (SHIELDS ON — Xera) Settings: master Switch + llUblockLists CheckBoxes + etAdBlockerListUrl

Why not a new engine?

We kept ad-block 0.0.4 .so to stay on the TV Bro Kotlin codebase you asked to keep. Swapping to mlm-games/adblock-rust (better $redirect/cosmetics) is a drop-in at the same seam (WebViewEx.kt:363 + AdblockModel) — no browser rewrite, React only for Settings if you want later.

Kept: master toggle single source of truth Expanded: dedicated card + overlay

  • ./gradlew :app:assembleGenericGeckoExcludedDebug → 12M APK (was 11M)
  • Output: releases/xera.apk + docs/apk/xera.apk (single apk in releases, as requested)
